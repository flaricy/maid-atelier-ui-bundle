# Security Policy

## Reporting a vulnerability

Please avoid posting exploit details, sensitive paths, tokens, or private data in a public issue.

1. If this repository has GitHub Private Vulnerability Reporting enabled, open the repository's **Security** tab and choose **Report a vulnerability**.
2. If that option is unavailable, open a minimal public issue stating only that you need a private channel for a security report. Do not include reproduction details until a maintainer confirms a private communication path.

Include affected versions, impact, and a minimal reproduction only in the private report. Please allow maintainers a reasonable opportunity to investigate and coordinate a fix before public disclosure.
